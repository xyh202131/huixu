# 一站式活动规划与执行 Agent

面向一年承办多场活动的团队，支持企业培训、行业论坛、展览、市集和校园活动。团队从一句话、批量资料或模板起步，在同一工作台维护计划、筹备、报名、发布、现场与复盘。涉及已发布安排的改动由负责人在一张变更单上核对并确认。

| [任务清单](task.md) | 全量功能的交付依赖、需求对应关系与验收场景 |
| [Agent 行为约定](agent.md) | 资料处理、校验、外部协作、改排、发布与发送权限 |

当前为 v0.2 设计评审。150 人论坛的换厅场景用于验证完整产品的变更流程。付费票务、选座退款与外部消息渠道按活动需要接入。

## 本地 Web 工作台

在项目根目录运行以下命令，然后打开 [会序工作台](http://127.0.0.1:5173/)。

~~~powershell
cd web
npm.cmd ci --ignore-scripts
npm.cmd run dev
~~~

五类活动可从顶栏切换。桌面左栏打开对应章节，右栏是可收起的 Agent 工作台。手机底栏提供概况、目录、现场和 Agent，Agent 和模型设置用全屏面板打开。默认论坛可从「变更单」比较 B 厅和 C 厅。登录后可发布 C 厅方案，再到议程、现场和材料章节核对。

外部表单、凭证核验和通知记录都在本机演练。共享权限、扫码摄像头、票务支付、退款及消息渠道服务待接入。

## 登录本机工作台

点击工作台头像打开账户弹窗。首次设置负责人姓名、邮箱和 12–128 位密码，此后在弹窗里登录或退出。可点右上角的关闭按钮或按 Esc 回到当前页面。认证使用 Better Auth，账号和会话存储在同一工作区标识下的 `auth.sqlite`。会话默认有效七天，退出时撤销当前会话。自定义路径使用 `HUIXU_AUTH_DB`，数据库路径须位于 Web 根目录之外。 [Better Auth 的 SQLite 配置](https://better-auth.com/docs/adapters/sqlite)

打开工作台即可浏览五类示例活动的七个章节，查看资料原文、议程、变更影响和现场大屏。访客可配置自己的模型并使用 Agent，查询当前活动、起草活动与变更建议。访客草稿保留在本次页面。登录后可访问已保存的活动、原件、索引和智能整理。活动草稿、嘉宾/供应商/志愿者协作演练及环节实绩仍保存在浏览器。报名和已发布的公开议程快照由服务端管理。运行 `npm test` 可执行认证和报名回流等流程测试。

## 现场整场救场

登录后进入「现场执行 → 上报问题」，选择会场关闭、嘉宾迟到或环节超时，填写事件和排程时间后点「生成整场调整方案」。示例论坛可以选择「A 厅关闭」，事件开始设为 12:50，查看城市共创圆桌和创新工作坊的备选。Agent 工作台也支持「A 厅 12:50 起关闭，最晚 18:00，生成整场调整方案」。

在变更单选一套方案，核对签到点、岗位和通知，再点击「确认发布并生成通知」。工作台、公开议程和已打开的大屏按发布版本更新。通知草稿可在发布记录核对对象及正文，沟通记录显示待发送。若报名、现场或议程已变更，变更单会要求重新计算。

## 报名、出席确认和真实邮件

- 登录后进入「报名与发布」。可以新增或编辑姓名、邮箱、分场、审核状态和备注，保存后服务端复查活动及分场名额。参与者报告无法参加时，保留原审批结果和凭证并释放名额。签到继续按原凭证核对。
- 点击「导入名单」可预览 Excel（XLSX、XLS）、CSV 或 TSV 的新增、更新、重复和待处理项。首行填写「姓名」，可加「报名编号」「邮箱」「分场」「审核状态」「备注」。分场可填名称或编号。同名且无法按编号或邮箱匹配时留给负责人核对。已有浏览器名单通过同一弹窗单独预览后迁移。
- 在「报名设置」发布公开活动页后可复制链接或二维码。参与者可提交报名，负责人在工作台查看同一份服务端名单。编辑一条审核通过的报名可生成或撤销专属确认链接，链接七天有效。参与者无需登录即可确认出席、报告无法参加或申请换分场。
- 真实邮件使用 Resend。在 `web/.env.local` 配置 `HUIXU_RESEND_API_KEY`、`HUIXU_MAIL_FROM` 和 `HUIXU_PUBLIC_ORIGIN`，重启服务。发件地址使用已验证域名。负责人在报名编辑里预览后点击「确认发送邮件」，再到「材料与沟通 → 出席确认邮件」查看服务受理、确认送达、失败和待核对的结果。明确提交失败的记录可单独重试。 [Resend 发信](https://resend.com/docs/api-reference/emails/send-email) · [Resend 投递查询](https://resend.com/docs/api-reference/emails/retrieve-email)
- 跨设备需要参与者能访问的 HTTPS 地址，并连接**同一个工作台服务及数据库**。先构建，再在反向代理后使用本机预览服务。对公网只转发活动页入口、构建后的静态资源和 `/api/registration-public/`，保留公网域名和请求 `Origin`，由工作台本机地址继续管理报名。确认请求的 `X-Huixu-Confirmation` 请求头要随请求转发。未配置公网地址时生成的链接仅供本机测试。服务端数据使用 Web 根目录以外的 `registration.sqlite`，可用 `HUIXU_REGISTRATION_DB` 指定同一份数据库。

## 接入 Agent 模型

点击右上角齿轮打开「模型设置」，访客也可配置。选择服务商后已填好默认模型，填入对应的 API Key 即可测试连接或保存。内置 OpenAI、Anthropic Claude、Google Gemini、DeepSeek、通义千问百炼中国内地和 MiniMax 中国。 [OpenAI](https://developers.openai.com/api/docs/models/gpt-5.4-mini) · [Claude](https://platform.claude.com/docs/en/models/haiku-5-5/overview) · [Gemini](https://ai.google.dev/gemini-api/docs/openai) · [DeepSeek](https://api-docs.deepseek.com/guides/tool_calls/) · [百炼](https://help.aliyun.com/en/model-studio/base-url) · [MiniMax](https://platform.minimax.cn/docs/api-reference/text-anthropic-api)

自定义接口支持 OpenAI Chat Completions 和 Anthropic Messages，可填服务基址或完整调用地址，以及模型名称和按需填写的 API Key。支持 HTTPS 或本机 HTTP。Anthropic Messages 可选择 `x-api-key` 或 `Authorization: Bearer`。连接测试使用示例请求核对工具调用与结果回传。

模型设置中可分别配置「Agent 对话」和「资料整理」。资料整理默认沿用对话模型，也可单独选择服务商。资料提取测试用虚构议程和海报检查两条冲突时间及对应出处。新整理任务读取当前配置，已完成的结果随资料版本保留。

配置与 API Key 保存在当前浏览器的 IndexedDB，刷新或重新打开页面后可复用。密钥输入框保持遮挡，留空沿用同一接口已保存的密钥。测试使用当前表单配置，保存后供后续请求使用。可移除某个用途的配置，资料整理随之恢复沿用浏览器内的对话模型。请求经本机服务临时转发至用户选择的模型接口。共享设备用完后可移除配置。登录负责人尚未设置浏览器模型时，继续兼容已有的本机模型数据库和环境变量。环境变量配置方式见 [web/.env.example](web/.env.example)。

工作台的本机开发与预览服务处理访客的 `/api/browser-agent` 和登录后的 `/api/agent`。模型可以读当前活动的议程与筹备、预算、报名汇总、现场和发布状态，准备活动草稿或提出换厅改时。登录后可检索已授权的活动资料。换厅提议沿用工作台的校验，发布需要负责人在变更单确认。调用提供商时发送问题、工具所需的业务摘要及获准引用的相关片段。报名名单和资料原件不随活动摘要发送。

配置缺失时可从 Agent 工作台打开模型设置或使用本机规则演练。静态 `dist` 需要配套服务端。Agent 对话当前为单轮，浏览同一活动的不同章节时保留这一轮的回答，也可查询该活动的持久化资料索引。

## 导入项目与活动记忆

从「活动概览 → 导入活动项目」用一批文件创建新活动，也可以到「资料与确认」追加文件或压缩包。资料写入本机 SQLite，解析完成后即可搜索原文、下载原件或导出 Markdown 知识页。压缩包有独立的文件清单，搜索结果会保留包内路径和页码、行号等位置。同名同内容重传去重，同名新内容保留旧版并使用新版做检索。默认仅供本机搜索，开启资料的 Agent 引用后，模型才能检索对应片段。

导入时勾选「允许 Agent 引用本批资料」，索引完成后自动整理。标准表格字段在本地提取，需理解上下文的片段交给已配置的模型。「Agent 智能整理」显示缺失项、并排冲突原文和提取出处。字段可以填写新值与依据、忽略或重新核对，未确认冲突可以先留空生成草稿。已有方案可勾选具体字段局部同步，其他手工修改保留。「活动记忆与索引 → 管理资料」支持每份资料的核对状态、按片段修改整理文字及单文件替换。修订会更新检索并保留原件与初始文字，停用资料退出当前检索与整理。整理结果、资料状态和文字修订保存在 SQLite，方案草稿和字段确认跟随浏览器活动数据。单次整理最多检查 2,500 个片段，其中最多 280 个非标准片段交给模型分批提取。未解析文件及未完成片段各有提示。

| 类别 | 可解析格式 |
| --- | --- |
| 文档与演示 | PDF、DOCX、RTF、PPTX |
| 表格 | XLSX、XLS、CSV、TSV |
| 文本与数据 | TXT、Markdown、HTML、JSON、JSONL、XML、YAML |
| 图片与扫描件 | PNG、JPEG、WebP、BMP、TIFF、GIF 和无文字层的 PDF 页，使用本机 OCR |
| 压缩包 | ZIP、7z、RAR、TAR、TAR.GZ、TAR.BZ2、TAR.XZ，以及 GZ、BZ2、XZ 单文件流 |

本机使用带 `node:sqlite` 和 FTS5 的 Node.js（本项目使用 Node.js 24），以及 Python 解析器。在 `web` 中运行 `python -m pip install --target .parser-deps -r server/requirements.txt` 可配置 Office、PDF 和 OCR 依赖。7z、RAR 使用本机 7-Zip，可从 PATH 或 Windows 安装位置识别，也可通过环境变量 `HUIXU_MEMORY_7Z` 指定。旧版 DOC、PPT 保存原件并提示转换为 DOCX、PPTX。加密、损坏或暂不支持的包内成员会显示状态，已完成的成员仍可检索。普通文件上限 12 MB，压缩包上限 48 MB，包内最多处理 300 项、3 层、累计展开 64 MB。扫描 PDF 和多帧图片会显示未处理的 OCR 范围。 [RapidOCR 配置文档](https://rapidai.github.io/RapidOCRDocs/main/en/install_usage/rapidocr/install/)

Windows 默认数据库在 `%LOCALAPPDATA%/Huixu/<工作区标识>/memory.sqlite`。如需指定位置，在本机配置 `HUIXU_MEMORY_DB` 并使用 Web 根目录之外的路径。索引按活动 ID 查询，活动计划和现场状态仍保存在当前浏览器。团队权限、审核后的跨活动知识复用和恢复演练见 [Agent 长期记忆设计](docs/agent-memory.md)。
