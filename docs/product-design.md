# 一站式活动规划与执行 Agent 产品设计

版本 v0.2 · 完整产品设计评审稿

## 1. 团队遇到的问题

一年办多场活动的团队往往已经有方案、名单、场地表、报价和执行台本。筹备时，同一安排散落在不同资料和聊天里，谁确认过哪个值要靠人工追查。现场一旦换厅、延期或换人，团队要同时修改议程、嘉宾行程、签到点、工作人员岗位和通知，还要核对观众最终看到了哪一版。活动结束后，下次办活动又要从旧文件中挑出能复用的部分。

**活动规划与执行 Agent** 把资料、筹备、报名、发布、现场和复盘放进同一个工作台。团队可以用一句话创建活动，也可以批量导入资料，得到能直接编辑和执行的计划。资料在活动中持续复用。每次变动都可以从同一计划追踪到受影响的安排，由负责人在一张变更单上核对并发布。

## 2. 用户与协作

首批服务一年承办多场活动的团队。企业培训、行业论坛、展览、市集和校园活动都在产品范围内。团队在活动列表看即将开场的活动、待确认资料、逾期任务、待发布变更和复盘进度，再进入对应活动处理。

| 角色 | 主要工作 | 能看到或操作的范围 |
| --- | --- | --- |
| 团队管理员 | 管理成员、活动权限、共享资源、模板和渠道 | 按组织权限管理跨活动内容 |
| 活动负责人 | 定目标和预算、处理取舍、确认发布 | 当前活动的计划、影响范围和发布记录，可指定现场发布人 |
| 策划与统筹 | 核对资料、排议程、分任务、协调场地与人员 | 被分配的活动和可编辑内容 |
| 招募、财务与资源负责人 | 审核报名、管名额、比价、确认支出和资源 | 与职责对应的名单、报价、预算或资源 |
| 现场总控与工作人员 | 更新实绩、上报问题、看岗位、扫码签到 | 按岗位查看分配的场次和必要的签到信息，总控按授权处理改排 |
| 嘉宾或讲师、供应商、志愿者 | 确认时段、交材料、提交报价、认领班次 | 通过专属链接查看和提交分配给自己的事项 |
| 观众、学员或参展人员 | 看议程、报名、候补、签到、领资料 | 公开内容和自己的报名、票据及行程 |

同一个人可兼任多个角色。公开页和现场大屏只展示对应场景需要的内容。报名联系方式、报价、预算、内部台本和未公开课件按授权查看。团队可以查看关键确认、发布和沟通记录。

本机工作台通过头像打开账户弹窗。首次使用时创建负责人账号，后续用邮箱和密码登录。可用右上角关闭按钮或 Esc 返回当前页面。登录前可查看工作台导航，活动内容、Agent、资料索引和智能整理要求有效会话。登录或退出后保留当前工作台页面，退出状态同步到同一浏览器的其他标签页。公开活动页和外部协作仍可通过原有演练链接进入。团队邀请、按角色授权和活动数据的服务端隔离纳入完整产品交付。

## 3. 一份计划怎样支撑多个页面

| 概念 | 团队可以把它理解为 | 使用方式 |
| --- | --- | --- |
| 活动计划 | 活动总表 | 维护目标、日期、议程、场地、人员、资源、预算和任务，衍生各角色需要的安排 |
| 待确认资料 | 带出处的核对清单 | 看上传原文和外部回复，补齐缺项、解决冲突、确认可用于排程的值 |
| 活动环节 | 计划中可以单独安排的一段工作 | 可以是讲座、工作坊、展区开放、布展、撤场或一个班次，按需要关联人员、空间、设备和名额 |
| 已发布版本 | 各方当前共同使用的执行安排 | 公开页、专属链接、现场看板和在线台本按当前发布版本展示各自内容 |
| 变更单 | 确认前的对照清单 | 看改动依据、旧值与新值、校验、待执行动作、通知对象和正文，确认后追踪结果 |
| 现场记录 | 当天执行日志 | 保留实际开场、结束、签到和事件处理时间，支持实时改排和会后对照 |
| 活动模板 | 下一场的可编辑底稿 | 复用流程、相对日期、任务依赖、岗位和物料清单，在新活动重新确认资源和人员 |

草稿可持续编辑，当前发布版本供各方执行，现场记录保留已经发生的事实。报名、外部回复和签到按实际进展更新。改期、换厅或改派时，沿用同一环节和相关记录，明确显示需要重新确认的报名、嘉宾安排和岗位。上传同一批资料之后，排程、材料和通知直接引用活动计划中的已确认内容。新文件或外部回复带来的不同值进入待核对列表。

## 4. 工作台入口

一场活动在一张纵向工作台中展开。顶部可切换活动、打开目录、新建活动、使用 Agent 或点击头像管理账户。目录默认收起，桌面从顶部按钮展开，手机从底部展开。滚动时更新当前章节，选中链接后定位到相应标题并把焦点交给正文。

| 章节 | 用户看到的内容与主要动作 |
| --- | --- |
| 活动概况 | 活动名称、时间、场地、关键进度和待办。可导入活动项目、定位议程或进入现场 |
| 资料与确认 | 批次进度、原文件、识别结果、并排原文、重复项与缺失项，确认或手工补录 |
| 方案与议程 | 活动目标、流程草稿、按日期和场地排列的环节、占用和冲突，编辑、拖动或用自然语言调整 |
| 筹备与协作 | 任务、负责人、设备、预算和供应商报价，可定位到嘉宾、供应商和志愿者的协作事项 |
| 报名与发布 | 公开页和二维码、审核、候补、分场名额、材料与沟通、变更校验和发布记录 |
| 现场执行 | 总控、岗位移动页、签到和大屏视图，记录实绩、上报问题、打开救场方案 |
| 复盘与模板 | 报名到场、预算、计划与实绩、资料和问卷发放、复制成模板 |

活动概况中的待办定位到具体事项。核对原文后可在同页继续处理草稿，章节跳转保留筛选与未保存输入。旧工作台链接可直接定位到对应章节或子节。公开报名和外部协作保留各自链接，现场大屏从现场章节打开。

Agent 在资料、方案、筹备和现场章节中使用当前活动的上下文。用户能从建议跳到原文、环节、人员或待办，继续手工编辑。

- 议程调整、任务编辑、Agent 和材料预览可在桌面侧栏打开，在手机上使用底部抽屉。通知预览打开后，如果修改材料或筛选条件，先刷新预览再确认发送。
- 发布变更时在确认窗中核对新安排、同步范围，以及本次选择的通知对象。将已确认报名转为候补时，在原操作旁确认并提示释放名额。
- 保存成功用短提示反馈。容量冲突、凭证问题和待处理结果留在对应操作区。键盘用户可在筛选组内用方向键切换，关闭确认后回到操作入口。系统启用减少动态效果时停用交互动效。
- 活动、场次、会场、角色和渠道等选项在当前页面就地展开，显示当前选中项。可用方向键浏览，用 Esc 关闭并保留原选项。日期、时间和文件沿用系统控件。
- 活动概览和公开活动页的浅色石纹缓慢流动。石纹离开视口或标签页切到后台时暂停。启用减少动态效果或浏览器无法渲染动效时显示静态原图。

## 5. 五类活动怎么使用

团队可以选活动类型作为起点，在同一工作台组合规则。多日活动、并行会场、连续占用和重复批次可共存。例如论坛也可以有全天展区，培训也可以有讲座和分组实操。

| 活动类型 | 典型计划结构 | 必须能处理的安排 |
| --- | --- | --- |
| 企业培训 | 多期课程、讲师、班组、教室和实操设备 | 按部门或班组导入名单，设置课程先后或前置条件，按批次分配容量，跟踪讲师课件和学员签到 |
| 行业论坛 | 主会场、平行分论坛、圆桌和工作坊 | 核对嘉宾跨会场时间和转场，管理分场名额与候补，按场次发布行程与救场变更 |
| 展览 | 展区、展位、开放时段、布展和撤展 | 连续占用场馆与展位，分别安排进场、开放和撤场窗口，管理展区容量、展商资料和临时关闭 |
| 市集 | 摊位、摊主、进撤场窗口、营业和轮班 | 核对摊位冲突、电力等资源和共享设备，管理分批进场、摊主岗位和观众动线 |
| 校园活动 | 场地、社团、签到点、志愿者班次 | 按活动配置场地审批与任务依赖，安排志愿者认领和交接，支持多签到点与分场报名 |

## 6. 九项能力

### 6.1 批量上传和整理资料

- 从活动概览选择「导入活动项目」创建活动并导入首批资料。后续可以在「资料与确认」追加文件或压缩包。逐文件展示索引状态、版本和原文位置。压缩包可查看成员及解析结果，从搜索或 Agent 引用进入包内原文片段。需要 Agent 引用时，可在导入时选择允许，也可在索引表中更改。
- 一次拖入表格、文档、PDF、图片和截图，可混合活动方案、Excel 名单、场地表、报价单和海报。逐文件显示识别中、可核对或需要手工处理。部分文件读取失败时，已处理文件和已确认内容仍可继续用。
- 识别活动时间、议程、嘉宾和名单、场地容量与设备、任务、预算和供应商报价。表格可确认列的用途，扫描页和截图可查看识别文字。提取结果可跳回页码、工作表与行号或图片位置。重复名单先给匹配建议，允许负责人核对同名人员或重复报名。
- 比对含义相同的字段。方案写圆桌 14:00、海报写 14:30 时，并排显示两个原文片段、文件名和位置。负责人可以选其中一个、填新值并说明依据，或保留待确认。缺失值和从上下文推测的值有明确标记。
- 识别结果归入同一活动计划。用户可补录或改正。新资料与已确认安排冲突时显示差异，并注明受影响的环节。只有确实依赖未确认信息的安排才限制发布，其余草稿工作可继续。

本机工作台在已允许 Agent 引用的批次索引完成后自动整理，也可在索引表开启引用来触发整理。「资料与确认」显示活动基本信息、议程、人员名单、场地与预算，注明整理覆盖范围。冲突并排展示当前版本的原文，沿用证据未变的已选值。缺失字段可留空生成草稿，在「方案与议程」补写、增删条目并保存。替换已有导入草稿需要确认，议程发布继续使用变更单。

导入区将文件选择和引用权限分开显示。整理区先显示已提取字段、待确认冲突和缺失项，再展示对照原文。窄屏按顺序堆叠原文卡片。方案编辑页提示未保存的修改，并将保存入口留在编辑区底部。

### 6.2 策划方案和智能排程

- 根据活动类型、目标、人数、预算、时段和可用场地生成可编辑方案，包含流程、时间、场地、人员安排和筹备任务。只有一句「我想办一场 150 人的论坛」时，先生成带假设的草案。日期未定可用相对时间，场地、嘉宾和预算等待确认。
- 支持日历、按场地的时间轴和表格。用户可以拖动、直接编辑，或说「把圆桌移到午餐后」。三个入口都显示改动结果、冲突及其证据。日期或环节有歧义时，给出可选择的范围。
- 排程检查跨日与并行占用、会场可用容量和分场确认人数、嘉宾与岗位可用时间、设备数量与搬运、布撤场和转场、课程先后或审批依赖。可将重要节点标为固定。尽量保住原时间、减少改派或控制追加成本作为可比较的偏好。
- 候选方案展示适用条件、预计预算变化、受影响的时段和人员。关键数据待确认时标记相应条件。设备不足、嘉宾重叠或容量超限等问题必须处理后才能发布涉及的安排。

### 6.3 筹备任务和资源管理

- 从活动日期或具体环节倒排订场、邀约、收课件、彩排、布展和撤场等任务。任务有负责人、截止时间、依赖和完成状态，可查看未分配、阻塞和逾期。临近截止时能筛选任务并预览提醒。
- 活动改期时，预览哪些相对截止日会重算，哪些已完成事项或固定期限需要人工核对。负责人可以修改任务或发给对应人员处理。
- 按时间、场地和数量安排设备、物料和岗位。显示可用、已预留、短缺以及调拨和交接。共享设备、场地或人员的跨活动冲突按团队权限提醒。
- 报价关联供应商、预算项、服务范围和有效期。可并排比较并记录采纳结果。预算、候选报价、已承诺金额和实际支出分别展示，活动复盘可以追到差异项。预算超出时展示增量及需要确认的取舍。

### 6.4 外部人员补资料

- 在活动中按角色和事项生成专属链接，负责人预览后发出，可查看待提交、待核对、已确认、过期或已撤销。链接只显示对应活动与本人事项，可设截止时间并撤销。
- 嘉宾或讲师查看分配的场次，确认时间或填写可用时段，上传课件。场次时间变更后可要求重新确认，已交课件保留在相应环节。
- 供应商查看询价事项和截止日，提交报价、交付条件及附件，可更新报价并保留版本供对比。供应商只看到自己的询价和回复。
- 志愿者查看可认领班次、地点和岗位要求。认领时检查班次名额、时间重叠和资格。取消或调班后更新缺岗和交接，负责人能看到待处理情况。
- 外部回复直接进入对应环节、询价或班次。涉及已发布安排、预算采纳或班次调整的提议，在工作台按权限核对并按需进入变更单。

### 6.5 发布活动页、报名和票务

- 从发布版本生成公开页、公开议程和可分享的报名二维码。支持只受邀访问的活动，负责人可预览对外展示范围、表单、报名开放时段和满员提示。
- 管理待审核、已确认、候补和取消。活动总名额与分场名额分别管理，可配置先到先得或审核。取消、释放名额和候补补位按活动规则执行，显示人选、回应期限和通知状态。并发确认按同一可用名额计算。
- 观众查看自己的分场、报名状态和签到凭证。报名二维码用于进入活动页，个人签到凭证用于核验身份与场次资格。场次容量或座位变化时，预览受影响的报名与候补及可选安排。
- **可接入的付费票务。** 活动可启用票种、价格、库存与支付时限，查看待支付、已支付、取消和退款状态。库存、分场名额和座位同时核对。启用选座时，展示可用、暂留、已占座位，支付超时后按规则释放。退款时核对原订单、退款范围、凭证状态以及是否释放座位和名额，结果可追踪。活动改期、取消或换厅涉及已售座位时，在变更单预览改座、确认或退款影响，再按活动规则与授权执行。

### 6.6 生成材料和统一沟通

- 用同一版计划生成观众议程、嘉宾行程、主持稿、工作人员执行台本和岗位清单。每份显示版本和适用人群。可在预览中编辑文案并保留人工补充。源计划改变时，标出需重新核对的手工内容。已下载的文件可从版本信息追到最新版。
- 可按报名状态、场次、角色或其组合选人，预览实际对象、人数、正文、附件和发送渠道，支持发送前去重并提示缺少联系方式的对象。内部台本、报价和受限课件按接收权限过滤。
- 支持邮件、日历邀请和站内公告。邮件与公告可以分人群预览。日历邀请随同一场次更新或取消原邀请，收件人能识别对应改动。发送后按渠道和对象查看已提交、失败、结果待核对及可用的送达状态。
- **可接入的外部渠道。** 飞书、企业微信和短信沿用相同的选人、预览、确认和发送记录，展示各渠道可用的目标、发送限制和结果。渠道部分失败时，负责人可以核对并重试明确失败的发送。

### 6.7 现场签到和执行

- 观众展示个人凭证扫码签到，工作人员查看核验结果。支持活动入场和分场签到，按资格提示错场、重复签到或需人工处理。核对后允许按权限补录并保留原因。重复扫码只计一次有效到场。
- 工作人员手机上可看当前和下一环节、负责的岗位、地点、集合时间、待办与异常入口。总控记录实际开始、结束、延时、跳过与问题，能追到相关岗位和处理人。现场大屏按会场显示当前和下一场及公开变更。
- 对照计划、已发布安排和实绩。现场可及时记录已经发生的进度，涉及后续安排的改动进入变更单。移动端和大屏在更新暂不可用时标记最后同步时间，工作人员能识别手头安排是否为最新。临时补录签到在联网后核对资格和重复记录。

### 6.8 现场救场

- 从场地关闭、嘉宾迟到、环节超时或人工上报进入。读取实际进度、已签到情况、已确认名额、剩余时段、可用会场和设备、相关人员与岗位，列出被直接影响的环节及后续连带变化。
- 可比较换厅、换序、推迟、替换嘉宾、拆分批次、缩短或取消等方案。逐项验证容量、设备、场地占用、嘉宾和工作人员时间、转场及已发生事项。方案显示能保住的安排、需要牺牲的目标、受影响人数和手工动作。
- 无可行方案时显示具体卡点。比如所有可用场地都装不下，或唯一合适会场的最早开始时间超出嘉宾可用时间。负责人可选择协调哪项条件，系统按新的条件重算。数据缺失或校验尚未完成时显示对应状态。
- 选定方案后进入同一张变更单。确认发布后更新议程、现场和大屏看板、岗位与台本，并生成受影响人员的通知供预览。负责人可以在发布时同时确认发送预览过的通知。

### 6.9 会后复盘和复用

- 选择观众、嘉宾、工作人员或特定场次的人群，预览后发资料和问卷，跟踪资料发送、问卷回复及所用活动版本。
- 按活动和分场看报名、审核、候补、确认与实际到场。报表显示统计口径，例如分场到场率按该场有效签到人数和确认报名人数计算。预算对照计划、承诺及实际支出，执行对照计划时间、实际时间、异常和处置。
- 可保存整场或选定部分为模板，复用议程结构、相对时间、任务依赖、岗位角色和物料清单。创建下一场时设置新日期，核对场地、负责人和可用资源。报名名单、外部链接、个人课件、签到和历史沟通记录留在原活动。
- 跨活动查看历史复盘和常用模板。可以对照资料到可执行计划的耗时、异常到发布的耗时，以及发布后仍需人工处理的项目，作为团队改善依据。
- 负责人可把适用条件明确的复盘结论纳入团队手册。Agent 在下一场活动可引用审核过的历史案例和检查步骤，并按当前活动重新核对时间、容量和资源。使用者可从知识页查看来源和最近核验时间。见 [Agent 长期记忆设计](agent-memory.md)。

## 7. 一张变更单如何完成发布

1. **提议。** 从拖动、手工编辑、自然语言或现场事件创建变更，展示原因、操作者、相关环节与当前发布版本。可把同一事件引起的多处调整一起预览。
2. **核对。** 并排看原安排、拟安排和依据。显示硬性约束、待确认事项与候选取舍。确认前复查场地、名额、资源、人员和实际进度。相关事实变化导致可行性、影响范围或收件对象变化时，更新预览供负责人重新确认。
3. **看清影响。** 列出将同步的公开议程、嘉宾行程、观众分场、签到点、志愿者岗位、工作人员台本和大屏。对物料搬迁、场地交接、需要嘉宾重新确认等人工动作，显示负责人和完成状态。涉及名额、座位、退款或已发日历邀请时，展示对应人群与动作。
4. **一次确认。** 有权限的负责人确认所选方案。可以选择「发布」或「发布并发送已预览通知」。本次发布包含变更单预览中的调整及关联项。其他筹备草稿继续单独编辑。同一确认只产生一次发布和对应的已授权发送。相关在线视图以同一发布版本为准，更新暂不可用的端显示已知版本和等待更新的状态。
5. **追踪。** 发布记录显示生效版本、操作者、更新情况、待执行动作和发送结果。确认的报名关系与历史签到可追溯。确定失败的通知可单独重试。发送结果待核对时保留原记录。发布后如需更正，在新变更单上再次确认。

### 工作坊换厅演练

150 人论坛有 72 人确认参加 14:00–14:40 的工作坊，A 厅临时关闭。负责人提出换到 B 厅。变更单列出 B 厅可用名额 60，超出 12 人，并同时核对 B 厅能否提供设备。C 厅可容纳 90 人，14:10 清场后需 10 分钟布置，最早可排到 14:20–15:00。嘉宾、设备和转场均通过校验后，C 厅方案可以进入发布。

负责人能在一张单上看到嘉宾行程、签到点、志愿者岗位、台本、大屏和 72 名已确认观众的通知预览。发布后观众沿用原工作坊报名，签到点和大屏展示新安排，搬移签到桌的任务有明确负责人。若嘉宾仅可用至 14:55，系统指出 C 厅方案也排不开，由负责人选择协调嘉宾、缩短时长或寻找其他可用会场，再校验和发布。
